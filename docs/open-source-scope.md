# 开源范围说明

这个仓库来自一个真实 Obsidian 自学系统的整理，但不是私人 Vault 的公开副本。

## 保留什么

保留的是可复用的方法：

- CourseOS / ResearchWiki / ProjectLab 三系统结构。
- raw/wiki 分离原则。
- learning session、problem loop、reading mission 等模板。
- agent 启动和协作 prompt。
- 隐私边界和发布检查清单。
- 一个脱敏的高数学习闭环示例。

## 模板化什么

这些内容只保留结构，不保留真实数据：

- 学习者画像。
- 课程进度。
- 资料接入队列。
- 外部资料索引。
- 错题索引。
- 项目能力树。
- 研究问题索引。

## 排除什么

以下内容不进入开源仓库：

- 真实课程资料和作业文件。
- 真实个人进度和生活记录。
- 本机绝对路径。
- 私人访谈和活动记录。
- 旧项目归档和外部代码。
- Obsidian workspace 状态。
- 附件和导出文件。

## 为什么这样做

SelfStudyOS 的价值不在某个具体学生的私人资料，而在一套可复制的学习闭环：

1. 选择最小学习范围。
2. 先让学习者尝试。
3. 用 agent 做诊断和分层提示。
4. 记录学习证据。
5. 只把验证过的理解沉淀进 wiki。

开源版应该让别人能复制这套机制，而不是复制一个人的私人 Vault。
