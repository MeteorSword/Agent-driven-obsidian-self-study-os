# 工作流

## Daily Start

用于每天开始学习。

1. 读 `01_LearningDesk/02_今日状态.md` 和 `03_行动队列.md`。
2. 检查当前课程中 `status: in-progress` 的 session/problem。
3. 若当前状态、课程 progress、MOC、总进度的下一步冲突，先报告冲突。
4. 选择唯一主任务。
5. 如果有到期复习，只提示“有到期复习，可切换复习模式处理”；不要展开 `Review/revision_notes.md`，不要插入复习任务。
6. 限定最小范围。
7. 让学习者先说明当前理解、尝试或卡点。
8. 开始 CourseOS、ResearchWiki 或 ProjectLab 工作流。
9. 结束时按 5 行收口写进 Daily Note。

## Course Session（开始学习模式）

用于学习一节课、一个概念或一组课件。

1. 读取课程 MOC 和 raw 队列。
2. 确认当前是开始学习模式，而不是作业模式或复习模式。
3. 选择一个小范围。
4. 问 2-5 个诊断问题。
5. 解释核心概念，但不长篇总结。
6. 要求复述、举例或做最小题；可以用桥接题，但要明确标记“桥接不计掌握”。
7. 不主动展开复习债务；只有直接阻塞本次主题时，才做 3-10 分钟前置工具补丁。
8. 记录掌握点、卡点和下一步（通过 5 行收口）。

## Problem Loop（作业模式）

用于作业、例题、错题订正中的做题环节。

1. 学习者先写出理解、思路、第一步或卡点。
2. Agent 判断卡点类型（主卡点 vs 末端错误）。
3. **Hint 1**：题型识别和第一步方向。
4. 学习者继续尝试。
5. **Hint 2**：关键公式或关键变形。
6. 仍卡住给 **Hint 3**：展开下一步，但不给完整答案。
7. 学习者尝试后仍卡住，才给完整解法。
8. 解后归因，决定是否进入错题卡。
9. 桥接题不计入作业完成度，也不作为掌握证据。
10. 不主动读取或展开复习债务；只有复习债务直接阻塞当前题时，才插入 3-10 分钟前置工具补丁。

## Course Review（复习模式）

用于冷复测、错题回看、间隔复习和概念查漏。

1. 读取 `01_LearningDesk/05_复习入口.md`、`03_行动队列.md` 中的 review 行，以及 `Review/revision_notes.md`。
2. 判断复习类型：冷复测 / 错题订正 / 概念查漏 / 间隔复习。
3. 冷复测先让学习者不看提示独立写。
4. 错题订正先让学习者复述原错因和这次检查步骤。
5. 概念查漏先问 2-3 个诊断问题，再做最小解释。
6. 记录通过方式：无提示 / Hint 1 / Hint 2 / Hint 3 / Solution 后订正。
7. 只有连续暴露同类问题时，才建议更新 `revision_notes`、错题卡或行动队列。

## Reading Mission

用于论文阅读。

1. 先定义为什么读这篇论文。
2. 选择目标等级 L0-L4（主线课程未跑通前不启动 L2 深读）。
3. 写清必须理解和可以忽略的部分。
4. 先做 global orientation，再钻一个局部点。
5. 把结论接回 ResearchWiki 的概念、连接或问题。

## Project Ability Mapping

用于项目和作品集。

1. 说明真实问题和用户。
2. 判断当前 demo 状态。
3. 拆分自己掌握的部分和 AI 代劳部分。
4. 暴露能力债务。
5. 选择一个最小可验证任务。
6. 把项目任务映射回课程基础或技能训练。
7. 如果当天主线课程完全没推进，先提醒做一个最小主线任务。

## 收口（每次 session 结束都要做）

用 [`vault-template/99_Meta/Templates/learning_close_5lines.md`](../vault-template/99_Meta/Templates/learning_close_5lines.md) 写 5 行进当天 Daily Note。详见 [`close-ritual.md`](close-ritual.md)。

不要让学习者手改 02 / 03 / 05 / 课程 progress。

## Weekly Review

用于每周复盘。

1. 看本周 Daily Note 5 行中真实独立产出有几天。
2. 看 Hint 1/2/3 分布 → 哪个主题最不稳。
3. 找出反复出现的“仍然不懂”→ 进 `Review/revision_notes.md`。
4. 找出没有闭环的 session。
5. 判断是否在用项目逃避基础训练。
6. 选择下周最小主线。
