# 工作流

## Daily Start

用于每天开始学习。

1. 查看 `Review/progress.md`。
2. 选择今天唯一主任务。
3. 把范围压缩到一个最小单元。
4. 让学习者先说明当前理解、尝试或卡点。
5. 开始 CourseOS、ResearchWiki 或 ProjectLab 工作流。
6. 结束时更新进度和下一步。

## Course Session

用于学习一节课、一个概念或一组课件。

1. 读取课程 MOC 和 raw 队列。
2. 选择一个小范围。
3. 问 2-5 个诊断问题。
4. 解释核心概念，但不长篇总结。
5. 要求复述、举例或做最小题。
6. 记录掌握点、卡点和下一步。

## Problem Loop

用于作业、例题、错题订正。

1. 学习者先写出理解、思路、第一步或卡点。
2. Agent 判断卡点类型。
3. 先给 Hint 1，不直接给完整解法。
4. 学习者继续尝试。
5. 必要时升级到 Hint 2、Hint 3、Solution。
6. 解后归因，决定是否进入错题卡。

## Reading Mission

用于论文阅读。

1. 先定义为什么读这篇论文。
2. 选择目标等级 L0-L4。
3. 写清必须理解和可以忽略的部分。
4. 先做 global orientation，再钻一个局部点。
5. 把结论接回 ResearchWiki 的概念、连接或问题。

## Project Ability Mapping

用于项目和作品集。

1. 说明真实问题和用户。
2. 判断当前 demo 状态。
3. 拆分自己掌握的部分和 AI 代劳部分。
4. 暴露能力债务。
5. 选择一个最小可验证任务。
6. 把项目任务映射回课程基础或技能训练。

## Weekly Review

用于每周复盘。

1. 看本周完成了哪些学习证据。
2. 找出没有闭环的 session。
3. 找出反复出现的错因。
4. 判断是否在用项目逃避基础训练。
5. 选择下周最小主线。
