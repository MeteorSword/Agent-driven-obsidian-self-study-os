## v1.0.0（当前目标）

目标是**可安装、可迁移、可公开分享**，而不是增加学习功能。

- **版本与标识**：SemVer + `99_Meta/SelfStudyOS_Version.md`，让任意 Vault 能判断自己的起点。
- **安装契约**：`docs/install.md`，说明 skill 装哪里、如何验证加载成功。
- **冷启动触发词**：说「冷启动」即可，不必每天粘贴长 prompt。
- **考试冲刺一等公民**：补齐第 4 个模式块，统一四模式口径。
- **规则单点化**：`operating_rules.md` 为唯一规则定义，其余文件引用而非复制。
- **课程档案**：`course_profile.md` 承载资料源、编号/页码口径、记号、勘误、不考范围。
- **模板收拢**：全部模板归入 `05_Templates/`，删除两处重复。
- **安全迁移**：只读扫描脚本，把旧 Vault 分成框架/用户数据/生成产物/私人资料四类，输出冲突与哈希。
- **发布检查**：`preflight.ps1` 覆盖绝对路径、邮箱、手机号、学号、大文件、断引用。

验收前提：**先在自己的私有 Vault 上跑通，再对外发布。**

## v1.1（计划）

- **prompt 资产库完整版**：`P-NN` 编号 + 变量化 + 查重 + 废弃/合并记录（v1.0 只做编号与位置）。
- **写入式迁移**：自动补齐框架文件、改写路径引用、生成回滚脚本与哈希验收（v1.0 只做只读扫描）。
- **lint 脚本**：概念卡是否有学习证据、行动队列是否有僵尸 P0、Daily Note 是否每天有 5 行落盘。
- **ResearchWiki 工作流**：Reading Mission 队列、L0–L4 分级、论文页与连接页。
- **ProjectLab 工作流**：能力树、AI 代劳部分标注、能力债务。
- **可选约定文档**：把"标签协议""绝对路径输出"等个人偏好整理成可选清单，与系统规则分离。

## v1.2+（展望）

- 英文 README。
- 更多课程示例（线性代数、计算机基础等），全部脱敏。
- Dataview 查询模板：统计 Hint 层级分布、反复"仍然不懂"项。
- Obsidian 插件最小配置建议。

## 明确不做

- 不整包引入外部 course-helper 类技能（重叠且规则冲突）。
- 不做"先给答案再给步骤"。
- 不生成可直接提交的作业稿。
- 不把某个 agent 平台的目录结构（如 `.dsh/skills`）当作唯一约定。
- 不引入插件或数据库依赖；核心资产始终是可读的 Markdown。
- 不把个人 Vault 数据合并进公共模板仓库。
