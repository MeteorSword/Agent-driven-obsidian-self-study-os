## 启动问题

1. 我今天要学什么？
   - 用球坐标写出半球区域的积分限。
2. 这个内容在课程里的位置是什么？
   - 属于三重积分换元，和柱坐标、Jacobian、体积元有关。
3. 我已经知道什么？
   - 知道球坐标大致形式：`x=rho sin(phi) cos(theta)`，`y=rho sin(phi) sin(theta)`，`z=rho cos(phi)`。
4. 我最可能卡在哪里？

5. 今天结束时，什么算完成？

## Agent 处理

### Global orientation

球坐标适合处理球、球壳、圆锥边界。它的核心不是把坐标公式背下来，而是看清：

- `rho` 控制离原点多远。
- `theta` 控制绕 `z` 轴转多少。
- `phi` 控制从正 `z` 轴向下转多少。

### Core extraction

- 上半球：`0 <= rho <= R`
- 绕一圈：`0 <= theta <= 2pi`
- 从正 `z` 轴到 `xy` 平面：`0 <= phi <= pi/2`
- 体积元：`dV = rho^2 sin(phi) d rho d phi d theta`

### Check understanding

Agent 问：

1. 为什么上半球不是 `0 <= phi <= pi`？
2. 如果是下半球，`phi` 范围怎么变？
3. 体积元里为什么不能漏掉 `sin(phi)`？

学习者回答后再进入最小题。
