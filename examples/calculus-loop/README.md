# Calculus Loop Example

这是一个脱敏的高数学习闭环示例，用来说明 SelfStudyOS 如何把一次学习从“听懂”推进到“有证据地掌握”。

示例主题：

- 重积分中的球坐标入门
- 半球区域的积分限
- 体积元和被积函数替换

包含文件：

- [`session.md`](session.md)：一次 learning session。
- [`problem-loop.md`](problem-loop.md)：一次 problem loop。
- [`concept-card.md`](concept-card.md)：学习后生成的概念卡。
- [`progress-after.md`](progress-after.md)：结束后的进度更新。

这个示例不是作业答案库。重点是流程：学习者先尝试，agent 分层提示，最后记录错因和下一步。
