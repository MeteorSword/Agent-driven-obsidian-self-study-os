# Problem Loop: 上半球积分限

## 基本信息

```text
日期：2026-05-24
课程：高等数学
题目来源：脱敏示例
题号：A1
相关知识点：球坐标、三重积分、体积元
```

## 题目

用球坐标表示区域：

```text
D = {(x, y, z) | x^2 + y^2 + z^2 <= R^2, z >= 0}
```

并写出 `∫∫∫_D 1 dV` 的球坐标形式。

## 第 0 步：用户先尝试

```text
我对题目的理解：
这是半径 R 的上半球。

我认为要用的知识点：
球坐标和体积元。

我的第一步：
rho 从 0 到 R，theta 从 0 到 2pi。

我卡住的位置：
phi 我不确定是 0 到 pi/2 还是 0 到 pi。
```

## 第 1 步：Agent 分层提示

### Hint 1

先不要看公式。想象 `phi` 是从正 `z` 轴往下转的角。上半球从正 `z` 轴开始，到哪里停止？

## 第 2 步：用户继续尝试

```text
根据提示后的尝试：
上半球到 xy 平面停止，所以 phi 应该是 0 到 pi/2。

新的卡点：
体积元我怕写错。
```

### Hint 2

球坐标体积元不是 `d rho d phi d theta`，需要乘上尺度因子：

```text
dV = rho^2 sin(phi) d rho d phi d theta
```

## 最终订正

```text
∫∫∫_D 1 dV
= ∫_{theta=0}^{2pi} ∫_{phi=0}^{pi/2} ∫_{rho=0}^{R}
  rho^2 sin(phi) d rho d phi d theta
```

## 错因

- 主要错因：概念不清。
- 具体表现：知道球坐标公式，但 `phi` 的几何方向不稳。
- 次要风险：容易漏体积元 `rho^2 sin(phi)`。

## 下次遇到同类题的检查清单

1. 先判断区域是否适合球坐标。
2. 先定 `rho`，再定 `theta`，最后用几何图像定 `phi`。
3. 看清 `phi` 是从正 `z` 轴向下量。
4. 写三重积分时检查体积元。

## 是否需要写入错题索引

需要。错因不是计算错误，而是球坐标角度含义不稳。
