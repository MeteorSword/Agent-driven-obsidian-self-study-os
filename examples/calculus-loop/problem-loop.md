## 题目

用球坐标表示区域

```text
D = {(x, y, z) | x^2 + y^2 + z^2 <= R^2, z >= 0}
```

并写出 `∫∫∫_D 1 dV` 的球坐标形式。

## 第 0 步：学习者先尝试（不跳步）

```text
我的理解：这是半径 R 的上半球。
我认为要用的知识点：球坐标和体积元。
我的第一步：rho 从 0 到 R，theta 从 0 到 2pi。
我卡住的位置：phi 是 0 到 pi/2 还是 0 到 pi。
```

## 第 1 步：Hint 1（只给题型识别与第一步方向）

`[Hint 1]` 先别看公式。`phi` 是从正 `z` 轴往下转的角。上半球从正 `z` 轴开始，到哪里停止？

## 第 2 步：学习者继续

```text
根据提示后的尝试：上半球到 xy 平面停止，所以 phi 是 0 到 pi/2。
新的卡点：体积元我怕写错。
```

## 第 3 步：Hint 2（只给关键变形）

`[Hint 2]` 球坐标体积元不是 `d rho d phi d theta`，要乘尺度因子：

```text
dV = rho^2 sin(phi) d rho d phi d theta
```

## 第 4 步：独立完成

```text
∫∫∫_D 1 dV
= ∫_{theta=0}^{2pi} ∫_{phi=0}^{pi/2} ∫_{rho=0}^{R}
  rho^2 sin(phi) d rho d phi d theta
```

通过方式：**Hint 2 后独立补齐**。

## 第 5 步：归因（区分主卡点与末端错误）

```text
主卡点：概念。知道球坐标公式，但 phi 的几何方向不稳。
末端错误：漏写体积元 rho^2 sin(phi)（属熟练度问题，不是能力缺口）。
```

错题卡和复习任务优先依据**主卡点**。

## 下次遇到同类题的检查清单

1. 先判断区域是否适合球坐标。
2. 先定 `rho`，再定 `theta`，最后用几何图像定 `phi`。
3. 确认 `phi` 从正 `z` 轴向下量。
4. 写三重积分时检查体积元。
