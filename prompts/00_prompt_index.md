# Prompt Index

这些 prompt 用于在新对话中快速进入 SelfStudyOS 的固定工作流。

使用方式：

1. 把 `<YOUR_VAULT_PATH>` 替换成你的 Obsidian Vault 路径。
2. 复制对应 prompt 的 `text` 代码块。
3. 作为新对话第一条消息发送给 AI agent。
