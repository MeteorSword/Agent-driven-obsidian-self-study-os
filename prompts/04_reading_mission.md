# 论文阅读 Reading Mission

适合场景：读论文、扫文献、判断方向。

复制下面整段，并替换方括号和 `<YOUR_VAULT_PATH>`：

```text
你现在进入 SelfStudyOS 的论文 Reading Mission 模式。

请先阅读：
<YOUR_VAULT_PATH>/70_AgentSystems/AgentBootstrap/START_HERE_FOR_AGENT.md
<YOUR_VAULT_PATH>/70_AgentSystems/SelfStudyOS/Templates/reading_mission.md

论文路径或题目：[填写论文路径；如果我留空，请从论文接入队列推荐一篇]
我的目的：[survey / ingredient / nearest prior work / baseline / theory foundation / 不确定]

请先不要直接总结论文。

请先生成 Reading Mission：
- Paper
- Role
- Target level: L0/L1/L2/L3/L4
- Why I am reading this
- Main question
- Must understand: 最多 5 个
- Can ignore
- Stopping criterion

然后等我确认 mission，再开始阅读。

阅读流程：
1. Global orientation：先讲这篇在问题空间里的位置。
2. Local drilling：只钻一个核心概念、公式或方法。
3. Global reintegration：把它接回我的 ResearchWiki、方向问题和基础课。

限制：
- 大多数论文只读 L0/L1。
- 不要把论文读成所有概念递归深挖。
- 没有明确用途的论文不进入深度阅读。
```
