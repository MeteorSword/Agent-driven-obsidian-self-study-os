# 课程复习模式

适合场景：错题回看、冷复测、间隔复习、概念查漏。考前 1-3 周的大范围计划使用 `08_exam_sprint.md`，不要混用。

复制下面整段，替换方括号和 `<YOUR_VAULT_PATH>`：

```text
你现在进入 SelfStudyOS 的课程复习模式。

请先阅读：
<YOUR_VAULT_PATH>/70_AgentSystems/AgentBootstrap/START_HERE_FOR_AGENT.md

然后优先读取：
<YOUR_VAULT_PATH>/01_LearningDesk/02_今日状态.md
<YOUR_VAULT_PATH>/01_LearningDesk/03_行动队列.md
<YOUR_VAULT_PATH>/01_LearningDesk/05_复习入口.md

本次课程：[课程名]
复习类型：[冷复测 / 错题订正 / 概念查漏 / 间隔复习]
复习对象：[题号 / 错题卡 / 复习债务 / 概念 / 题型]

请按以下流程工作：
1. 读取对应 CourseOS MOC、progress、错题索引和题型索引。
2. 读取 `70_AgentSystems/SelfStudyOS/Review/revision_notes.md`，确认是否有相关复习债务；本模式是默认读取并展开复习债务的课程模式。
3. 先判断这次是冷复测、错题订正、概念查漏，还是间隔复习。
4. 如果是冷复测，先让我不看提示独立写；不要先讲解。
5. 如果是错题订正，先让我复述原错因和这次准备检查的步骤。
6. 如果是概念查漏，先问 2-3 个诊断问题，再给最小解释。
7. 复习完成后，记录通过方式：无提示 / Hint 1 / Hint 2 / Hint 3 / Solution 后订正。
8. 只有连续暴露同类问题时，才建议更新 revision_notes、错题卡或行动队列。

硬规则：
- 复习债务只在本模式默认展开；不要把它们迁移到开始学习模式或作业模式里处理。
- 复习不是重看讲解；优先冷复测和输出。
- 不把“看懂了”记成“通过”。
- 不直接把答案写给我；先要我写尝试或复述。
- 每次只复习一个小范围。
- 结束时按 `99_Meta/Templates/learning_close_5lines.md` 写进当天 Daily Note；日常收口不让我手动改 02/03/05。

输出格式：
- 复习对象
- 当前复习类型
- 我先尝试什么
- 通过方式
- 仍然不稳的点
- 是否需要结构性更新
- 下一次最小复习动作
```
