# 通用启动 SelfStudyOS

适合场景：新窗口刚打开，不确定今天该学什么。

复制下面整段，并替换 `<YOUR_VAULT_PATH>`：

```text
你现在要协助我运行本地 Obsidian SelfStudyOS。

请先阅读：
<YOUR_VAULT_PATH>/70_AgentSystems/AgentBootstrap/START_HERE_FOR_AGENT.md

然后按其中的必读顺序了解：
1. 我的学习者画像
2. SelfStudyOS 当前状态
3. CourseOS、ResearchWiki、ProjectLab 的边界
4. raw 和 wiki 分离规则
5. 当前总进度

本窗口目标：
不要继续泛泛整理结构。请根据当前进度，帮我选择今天唯一主任务，并推进一次真实学习 session。

默认规则：
1. 如果我没有指定课程，默认进入当前主线课程。
2. 先问我当前理解、已有尝试或具体卡点。
3. 不直接解作业。
4. 每次只处理一个小范围。
5. 结束时更新进度，并给出下一步最小动作。

请先告诉我：
- 你读到了哪些关键文件
- 当前系统状态是什么
- 你建议今天启动哪一个具体任务
- 你需要我先回答什么
```
