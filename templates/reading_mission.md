# Reading Mission

适用：论文阅读、技术报告、综述文章。

## 基本信息

```text
Paper：
Path/URL：
Role：survey / ingredient / prior work / baseline / theory foundation
Target level：L0 / L1 / L2 / L3 / L4
```

## 阅读等级

- L0：知道这篇论文研究什么问题，结论是什么。
- L1：理解核心 claim、evidence、limitation。
- L2：理解方法结构和关键公式。
- L3：能复现或实现关键部分。
- L4：能批判、扩展或用于自己的研究。
