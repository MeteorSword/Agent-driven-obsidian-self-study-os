# 课程入口

要进入某门课时，从这里点。

## 当前课程

> 改成你自己的课。每门课只需要一个 MOC 入口；其它细节（错题/概念/题组）让 agent 自己进。

| 课程 | 入口 | 现在状态 |
|---|---|---|
| 示例课 | [[CourseOS/ExampleCourse/ExampleCourse-MOC\|示例课 MOC]] | 已激活：当前主线 |

状态说明：

- **已激活**：当前主线或随时可进入做作业的课。
- **待启动**：在系统里，但本试运行期间不主动推进。
- **占位**：MOC 是空壳，等真正要学时再展开。

## 课程资料

> 实体资料放 `10_Courses/<课程名>/`。这里只放一个指引。

## 进入课程后我要做什么

- **做作业**：打开课程 MOC，找到当前作业题，先自己写一段尝试或思路，再让 agent 给 Hint。
- **学新内容**：让 agent 把范围压到一节、一个概念，先做诊断问题，再决定下一步。
- **做复习**：先回 [[05_复习入口|复习入口]]，按到期复习走，不要重看讲解。
- 每次只处理一个小范围（一节 / 一题 / 一个概念）。
- 先自己尝试，再让 agent 提示。
