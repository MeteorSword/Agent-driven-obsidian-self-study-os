# 复习入口

要做复习、冷复测或错题回看时，从这里开始。

## 先看哪里

1. [[03_行动队列|行动队列]]：看今天到期的复习。
2. [[70_AgentSystems/SelfStudyOS/Review/revision_notes|复习债务]]：看长期不稳的点。
3. [[70_AgentSystems/SelfStudyOS/Review/mistakes/mistake_index|错题总索引]]：看错题。

## 当前先复习

> 由 agent 在每天 Daily Start 时根据 03_行动队列 的 review 项更新这一段，不需要学生本人维护。

- 示例：高次三角函数积分，不看提示重算三个一元积分。

## 我怎么判断自己会了

| 等级 | 判定 |
|---|---|
| 看懂 | 听解释后能跟上 |
| 提示后会做 | Hint 后能完成 |
| 当场独立会做 | 同 session 内无提示做出 |
| 冷复测通过 | 隔天或几天后无提示做出 |
| 变式通过 | 新题型或混合题能处理 |

## 复习完怎么记

不用手动改这一页或 03。agent 会按 [[99_Meta/Templates/learning_close_5lines|学习结束 5 行]] 写进当天 Daily Note。在 5 行的「今天处理了什么」里要写清楚：

- 复习的具体题号或知识点
- 通过方式：无提示 / Hint 1 / Hint 2 / Hint 3 / Solution 后订正
- 是否冷复测通过
- 下一次复习日期建议

如果冷复测连续未通过，agent 应在 [[70_AgentSystems/SelfStudyOS/Review/revision_notes|复习债务]] 对应条目更新「下次复习动作」，而不是只写进 Daily Note。
