# 复习入口

要做复习、冷复测或错题回看时，从这里开始。

复习债务只在这里对应的复习模式中展开。平时做作业或随堂学习时，agent 最多提示“有到期复习”，不主动打开债务清单；除非某个债务直接阻塞当前题，才允许做一个很小的前置工具补丁。

## 先看哪里

1. [[03_行动队列|行动队列]]：看今天到期的复习。
2. [[70_AgentSystems/SelfStudyOS/Review/revision_notes|复习债务]]：看长期不稳的点。
3. [[70_AgentSystems/SelfStudyOS/Review/mistakes/mistake_index|错题总索引]]：看错题。

## 选择复习模式

| 模式 | 什么时候用 | 先做什么 |
|---|---|---|
| 冷复测 | 行动队列里有到期 review，或某个债务需要验证 | 不看提示先写答案、步骤或判断 |
| 错题订正 | 回看某道错题或 problem loop | 先复述原错因和这次检查步骤 |
| 概念查漏 | 某个定义、公式、适用条件不稳 | 先回答 2-3 个诊断问题 |
| 间隔复习 | 章节放行后做短复测 | 先从 [[03_行动队列\|行动队列]] 或 [[70_AgentSystems/SelfStudyOS/Review/revision_notes\|复习债务]] 取一个最小对象 |

本页不保存具体复习对象。今天该复习什么，以 [[03_行动队列|行动队列]] 和 [[70_AgentSystems/SelfStudyOS/Review/revision_notes|复习债务]] 为准。

## 我怎么判断自己会了

| 等级 | 判定 |
|---|---|
| 看懂 | 听解释后能跟上 |
| 提示后会做 | Hint 后能完成 |
| 当场独立会做 | 同 session 内无提示做出 |
| 冷复测通过 | 隔天或几天后无提示做出 |
| 变式通过 | 新题型或混合题能处理 |

## 复习完怎么记

不用手动改这一页或 03。agent 会按 [[99_Meta/Templates/learning_close_5lines|学习结束 5 行]] 写进当天 Daily Note。在 5 行的「今天处理了什么」里要写清楚：

- 复习的具体题号或知识点
- 通过方式：无提示 / Hint 1 / Hint 2 / Hint 3 / Solution 后订正
- 是否冷复测通过
- 下一次复习日期建议

如果冷复测连续未通过，agent 应在 [[70_AgentSystems/SelfStudyOS/Review/revision_notes|复习债务]] 对应条目更新「下次复习动作」，而不是只写进 Daily Note。
