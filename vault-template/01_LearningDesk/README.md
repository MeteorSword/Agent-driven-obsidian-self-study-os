# 01_LearningDesk

学生侧唯一入口区。这一目录是 SelfStudyOS 给真实学生的「每天开门」位置。

## 设计原则

- 学生每天只打开本目录里的页面，不需要进入 `70_AgentSystems/`。
- 这里没有任何 agent prompt 工程的细节，全部是「我今天要做什么」级别的语言。
- `01_LearningDesk/06_给Agent的启动句.md` 是 agent 新会话的唯一入口，含必读顺序和执行指南。

详见 [`docs/entry-separation.md`](../../docs/entry-separation.md)。

## 文件清单

- `01_学习首页.md` — 每天先打开它。
- `02_今日状态.md` — 现在主线 / 今天唯一主任务 / 进展标准。
- `03_行动队列.md` — 真正要做的任务表 + stale 规则。
- `04_课程入口.md` — 进入哪门课。
- `05_复习入口.md` — 做到期复习、冷复测、错题回看。
- `06_给Agent的启动句.md` — 新开 agent 对话时复制粘贴的 prompt。

## 怎么用

复制本目录到你的 Vault 后：

1. 改 `01_学习首页.md` 的「当前主线」表，填你正在学的课。
2. 改 `02_今日状态.md` 的「当前主线 / 今天唯一主任务 / 进展标准」段。
3. 改 `03_行动队列.md` 的「当前队列」表，删掉示例行，加你自己的。
4. 改 `04_课程入口.md` 的课程表。
5. `06_给Agent的启动句.md` 里把 `<YOUR_VAULT_PATH>` 替换成绝对路径。
6. 之后每天只用打开 `01_学习首页.md`。
