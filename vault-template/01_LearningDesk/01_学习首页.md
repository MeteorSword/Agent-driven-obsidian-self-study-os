# 学习首页

每天学习时只打开这一页。

这是**学生侧唯一入口**。`70_AgentSystems/` 里的所有文件都是 agent 后台读的，不需要你每天打开。

## 今天先做什么

1. 看 [[02_今日状态|今日状态]]，确认当前状态和今天唯一主任务。
2. 看 [[03_行动队列|行动队列]]，选择一个 open 的 P0/P1 任务。
3. 判断本次模式：作业模式 / 复习模式 / 开始学习模式。
4. 如果要新开 agent 对话，复制 [[06_给Agent的启动句|给 Agent 的启动句]]，再追加本次模式块。

## 状态在哪里

本页只做通用启动，不保存具体题号、章节或复习对象。

## 我需要记住

- 每天只选一个主任务。
- 当前任务以 [[02_今日状态|今日状态]] 和 [[03_行动队列|行动队列]] 为准，不从本页判断。
- 作业题先自己尝试，再让 agent 提示。
- 给 Hint 后先继续写，不要马上要完整答案。
- 复习债务只在复习模式展开；作业和开始学习时只提示有无到期复习。
- 学完由 agent 按 [[99_Meta/Templates/learning_close_5lines|学习结束 5 行]] 写进当天 Daily Note；只有主线、任务状态、错题或复习债务发生结构性变化时，才更新 [[02_今日状态|今日状态]] 和 [[03_行动队列|行动队列]]。
