# 学习首页

每天学习时只打开这一页。

这是**学生侧唯一入口**。`70_AgentSystems/` 里的所有文件都是 agent 后台读的，不需要你每天打开。

## 今天先做什么

1. 看 [[02_今日状态|今日状态]]，确认现在主线是什么。
2. 看 [[03_行动队列|行动队列]]，选一个 P0 任务。
3. 如果有到期复习，先做 10-15 分钟复习热身。
4. 如果要新开 agent 对话，复制 [[06_给Agent的启动句|给 Agent 的启动句]]。
