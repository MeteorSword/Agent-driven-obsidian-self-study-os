# 行动队列

这里放近期真正要做的学习任务。每天先看 P0。

## 怎么选

- `P0`：今天优先做。
- `P1`：今天有余力再做。
- `P2`：暂时保留，不抢主线。
- `parked`：先放着，不默认安排。

## stale 规则

- `review` 类任务逾期 ≥ 3 天未做：直接 archive，复习动作并入 [[70_AgentSystems/SelfStudyOS/Review/revision_notes|复习债务]]。
- `homework` / `proof-debt` 类任务逾期 ≥ 7 天未做：先和学生确认还要不要做，再决定 archive 或降级。
- 不要把过期任务当作今天 P0 自动选中。完整规则见 [[70_AgentSystems/SelfStudyOS/System/operating_rules#行动队列 stale 规则|运行规则]]。

目的：防止队列积累僵尸 P0，让"今天 P0"始终是真实可做的当天动作，而不是过期承诺。

## 做完后怎么记

不用手动改这一页。agent 会按 [[99_Meta/Templates/learning_close_5lines|学习结束 5 行]] 把今天会话写进当天 Daily Note。

只有发生下面这类结构性事件时，agent 才另外改文件：

- 出现新错题 → 加错题卡 + 课程 progress 错因表加一行
- 出现新复习债务 → [[70_AgentSystems/SelfStudyOS/Review/revision_notes|复习债务]] 加一段
- 完成新题号 → 课程 progress「已完成题目」加一行
- 主线推进到新章 → 改 [[02_今日状态|02_今日状态]] 顶部的当前主线表
- 任务完成 → 在本队列把对应行 status 改为 `done`，或符合 stale 规则时 archive
