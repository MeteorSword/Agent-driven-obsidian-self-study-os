# 学习结束 5 行（canonical close template）

每次学习/复习/作业结束，agent 把这 5 行追加到当天的 Daily Note 「复盘」段下面。

这是 SelfStudyOS 的核心收口仪式：用 5 行替代手动更新 02_今日状态 / 03_行动队列 / 05_复习入口 / 课程 progress 等多个文件。

## 落盘流程（agent 必读）

1. 确定今天日期 `YYYY-MM-DD`。
2. 检查文件 `50_LifeOps/Logs/Daily/YYYY-MM-DD.md` 是否存在。
3. **如果不存在**：按 [[99_Meta/Templates/daily_note|daily-note 模板]] 先创建一份；frontmatter 里的 `date` / `created` / `updated` 填今天。不要因为"没有 Daily Note"就跳过收口。
4. 在「复盘」段下面追加下面的 5 行。如果「复盘」段已有内容，新增一段「### 学习结束 5 行 · 时间段标签」分隔，不要覆盖既有内容。
5. 学生本人不需要改 02_今日状态 / 03_行动队列 / 05_复习入口 / 课程 progress 中的任何一个；5 行模板替代日常收口。

只有发生**结构性事件**时才另外改文件：

- 出现新错题 → 加错题卡 + 在课程 progress 错因表加一行。
- 出现新复习债务 → 在 [[70_AgentSystems/SelfStudyOS/Review/revision_notes|复习债务]] 加一段。
- 完成一个新题号 → 在课程 progress「已完成题目」加一行。
- 主线推进到新章/新模式 → 改 [[01_LearningDesk/02_今日状态|02_今日状态]] 的「当前主线」表。
- 任务完成或被 archive → 在 [[01_LearningDesk/03_行动队列|03_行动队列]] 更新 status。

## 模板

```text
### 学习结束 5 行 · YYYY-MM-DD · 时间段或主题

1. 今天处理了什么：<具体题号 / 章节 / 概念，不写"高数"这种泛词>
2. 我自己完成的：<不看提示独立写出的部分，如果没有就写"无"，不要美化>
3. AI 帮了什么：<给了哪一层 Hint / 解释了哪个概念 / 检查了哪步>
4. 仍然不懂的：<具体卡点，写到能在下一次成为一道复测题的颗粒度>
5. 明天最小动作：<一个具体动作，30-60 分钟内可完成；不写"继续学高数">
```

通过方式可选附加在第 1 行末尾：`通过方式：无提示 / Hint 1 / Hint 2 / Hint 3 / Solution 后订正`

## 真实示例（照这个粒度写）

假设今天 2026-06-07 做了 `8.5-6` 的第一步分析：

```text
### 学习结束 5 行 · 2026-06-07 · 8.5-6 第一步

1. 今天处理了什么：高数第八章 `8.5-6` 第二型曲面积分；只完成第一步——曲面方向、投影区域、判断转哪类二重积分。通过方式：Hint 2。
2. 我自己完成的：写出曲面外法线方向和投影区域 `D_xy`；判断需要拆成两片处理。
3. AI 帮了什么：给了 Hint 1（提示这是第二型曲面积分要转有向面积元 `dy dz` / `dz dx` / `dx dy`），并在我写错投影区域符号时给了 Hint 2（指出上下两片符号相反）。
4. 仍然不懂的：上下两片的法向量定向与有向面积元符号的对应关系，凭直觉判断不稳；下一道同类题需要先写"外法线方向 → 各分量符号 → dy dz / dz dx / dx dy 符号"的小表格。
5. 明天最小动作：在 `8.5-6` 上把第二步写完——把 `P dy dz + Q dz dx + R dx dy` 真正代入并算出第一片的二重积分；不开新题。
```

不要写成这样（反例）：

```text
1. 学了 8.5
2. 大概会了
3. AI 给了一些提示
4. 还有点不懂
5. 明天继续
```

## 不允许

- 不写"今天学了挺多"、"基本掌握"、"差不多会了"——必须有具体证据。
- 不把 AI 帮的内容写到「自己完成的」一栏。
- 不把"看了视频/读了讲义"算作完成，除非有独立产出。
- 不因为今天没建 Daily Note 就跳过 5 行；先创建后追加。
