# 电路题硬约束

由某次电路图题暴露：AI 在做电路题时容易（1）不先重述拓扑直接算，导致漏元件、错节点；（2）凭语感判断电压源方向，KVL 符号搞反。

## Rules

**1. 出题/解题前必须先重述拓扑**

收到电路图后，先用文字写出：
- 节点列表（A, B, C, D...，以及它们物理上在图的什么位置）
- 每条支路连接的两个节点、上面的元件清单、参考方向
- 等用户确认"对"或修正后再开始算

**禁止：** 看到图就直接列方程。

**2. KVL 走环路必须逐元件列符号**

写 KVL 方程时不能心算"这个升、那个降"。每经过一个元件单独写一行：

```
左下 → 左上 沿 1Ω：电流朝上 3A，从下端（高位）到上端（低位） → 电位变化 -3V
左上 → 上中 沿 U：从 + 端走到 - 端 → 电位变化 -U
上中 → 右上 沿 3A 电流源：跳过（电流源没电压值，但记下还需 KCL 用）
...
```

把每行写出来后再求和列方程。

**3. KCL 必须列出节点的所有支路**

写 KCL 前先在节点旁画出"流入"和"流出"两栏，把每条接入这个节点的支路写进去，确认没有遗漏（包括电流源、跨节点的电阻支路、其他电压源等）。

## Why

电路图的拓扑和方向是采分细节，AI 凭"印象"做容易出错。强制"先描述后计算"能把错误前移到拓扑描述阶段，用户当场就能纠正，而不是算完结果才发现错了。

## How to apply

- 凡是电路题，第一句必须是"我看到的拓扑是 ..."，等用户确认后再开始算
- KVL/KCL 每步单独一行写明方向，不要把多步压缩到一行
- 如果用户已经给了答案让我验算，我也按这套流程走一遍，不能直接"看一眼答对没有"
