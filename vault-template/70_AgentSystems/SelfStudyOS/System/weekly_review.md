# Weekly Review

周复盘问题的唯一定义。其他文件（prompts/07_weekly_review.md、study_plan_template.md 周复盘段）引用本文件，不自行定义问题。

## 检查问题

1. 本周有哪些真实学习证据？（独立做对的题、独立写出的推导）
2. 本周哪些只是看懂解析/整理结构，没有做题、复述或推导？（虚假进展）
3. 哪些错因反复出现？
4. 哪些任务被推迟了？为什么？
5. 是否出现用项目或整理系统逃避基础课的情况？
6. 下周唯一主线是什么？

## 输出格式

```text
本周有效进展：
本周虚假进展：
最大能力缺口：
下周唯一主任务：
明天第一步：
```
