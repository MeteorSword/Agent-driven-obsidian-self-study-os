# 会话节奏与题源

本文件定义一次会话怎么排、题从哪里来、什么算证据。规则用 `ExampleCourse` 举例，不含任何真实课程或真题。

## 一、滚动作业

会话开始只承诺一段，一段不超过三个动作。一段完成立刻收口一小句，再决定下一段。不在会话开头排满整块时间。

段只有六种：

```text
定靶    选一个子问，说出它考哪个考点
工具    只推必须用的公式与边界条件
示范    agent 完整做一遍并说出决策依据
半完成  agent 给前两步，用户完成后两步
独立    换一个变体，闭卷，不给提示
收口    5 行与 frontmatter
```

提前完成时按顺序取用剩余时间：

1. 同题变体（一次只改一个条件）
2. 该课另一个 P0 子问
3. 另一门课的保卫线

## 二、时间不由 agent 估算

1. agent 不分配分钟预算，只分上面六种段。
2. 每段以产出结束，不以时间结束。
3. 收口的 `minutes` 由用户提供，agent 不估算。
4. 需要限时训练时，由用户计时并报结果。
5. agent 不说「这个大概要多久」。

## 三、题源与变体

1. 不得自拟题。题源只来自真题、教材习题、作业。
2. 一道真题可按六个维度衍生变体，一次只改一个维度：

| 维度 | 取值举例 | 改变什么 |
|---|---|---|
| 源分布 | 同心 / 偏移 / 连续体 | 对称性是否成立 |
| 净电荷或总量 | 0 / Q0 / 由边界条件反解 | 最外层结果 |
| 边界条件 | 悬空 / 内接地 / 外接地 | 零势点与未知量 |
| 介质或材料 | 单一 / 分层 | 本构关系 |
| 参考点 | 无穷远 / 界面 / 中心 | 常数项 |
| 求的量 | 场 / 通量 / 势 / 密度 / 能量 / 力 | 是否再积一次 |

3. 同时改两个及以上不叫变体，叫新题，会产生不可归因的错因。
4. 只改数值不叫变体，属机械重复，禁止。
5. 第四类变体为找错型：agent 从真题解答里改错一处，用户只定位与解释。此类只记诊断证据，不记求解证据。
6. 变体标注格式：`变体@<来源题号>-V<n> <改动说明>`。

## 四、冷复测防火墙

安排冷复测前必须同时满足四项：

1. 上次证据等级是独立或变式
2. 距上次至少一天
3. 距考试四天以上
4. 该考点已有一次完整正确路径

任一项不满足，跳过冷复测，改为结构提问加单点补缺，限时五分钟。

以下情形必须跳过：

- 上次是提示后完成或示范后完成
- 上次失败且未订正
- 同一天内第二次
- 距考试三天内且该考点还没有一次完整正确路径
- 用户明确说没有意义

跳过时改为问结构问题：这题情境分几段，边界在哪。

## 五、同题重写禁令

1. 同一子问连续尝试上限两次。
2. 第二次不得是原样重写，必须换题、换子问或换条件。
3. 超限停止本题，记为未通过。
4. 用户质疑「重写有没有用」时视为有效信号，立即停止重写。

## 六、证据等级与记录

| 等级 | 判据 | 能否升级 |
|---|---|---|
| 看懂 | 能一句话说出为什么这样分段 | 否，只作为进入下一步的许可 |
| 桥接 | 在 Hint 1 或 2 下完成 | 记为桥接，不计作业题通过 |
| 作业题通过 | 无提示、闭卷、限时，完成同一题 | 是 |
| 变式通过 | 在变体或同构异形上完成 | 是 |

证据必须来自此前未做过的题或变体。同一题重复完成只记为复现，不改变等级。

`mastery` 写作「等级@题号」：

```yaml
mastery: 桥接@Exam-2024-Q3
```

## 七、示范与半完成的标记

零基础且距考试七天以内时，示范与半完成是合法动作，必须显式标记：

```text
D 示范：用于建立路径，不构成掌握证据
S 半完成：用于建立中介步骤，不构成掌握证据
```

限制：示范单次不超过一段，半完成不超过一段。两者都不计入作业题通过。

## 八、判断是知识缺失还是提取失败

用户第一次完全忘记时，先问一个结构问题，限三十秒：

| 回答 | 判断 | 动作 |
|---|---|---|
| 说不出结构 | 知识缺失 | 讲工具加示范，换更小变体，不硬刚原题 |
| 能说结构算不出 | 提取或技能失败 | 给 Hint 1，再 Hint 2，不给 Solution |
| 能起步中途卡 | 局部缺口 | 只补那一步，回原题 |
| 读不懂题意 | 前置缺失 | 换更小变体或换同构题 |

不允许直接讲解原题全解。
