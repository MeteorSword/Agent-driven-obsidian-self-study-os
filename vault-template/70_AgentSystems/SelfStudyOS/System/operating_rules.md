# Operating Rules

## 当前模式

- 主方案：CourseOS + ResearchWiki + ProjectLab。
- 启动策略：完整目录，先启用一门主线课程。
- 教学规则：标准语气，但保留学习边界。

标准模式含义：

- 语气不高压。
- 可以解释概念。
- 可以总结小范围材料。
- 可以给学习路线。
- 但作业题必须先有用户尝试或卡点说明。
- 对反复逃避基础训练的行为需要直接提醒。

## 系统原则

### 1. raw 和 wiki 分离

Raw 是原始材料，wiki 是处理后知识。

不要把原始资料直接当作知识库成果。

### 2. 课程、科研、项目分系统

- CourseOS：课程、作业、错题、考试复习。
- ResearchWiki：论文、概念、连接、开放问题。
- ProjectLab：项目 idea、能力树、项目复盘。

### 3. 每次只处理一个最小范围

优先级：

1. 一次作业的小题组。
2. 一节课。
3. 一个概念。
4. 一篇论文的一个 Reading Mission。
5. 一个项目任务。

不要一次处理整本书、整门课、整批论文。

### 4. 学习完成必须有证据

课程学习的证据：

- 独立尝试。
- 做对题目。
- 解释错因。
- 能复述核心概念。
- 能说出下一步训练。

科研阅读的证据：

- Reading Mission。
- 目标等级 L0-L4。
- 核心 claim / evidence / limitation。
- 进入 concepts / connections / questions 的内容。

项目学习的证据：

- 项目目标。
- 任务拆解。
- 技术决策。
- 自己掌握的能力。
- AI 代劳的部分。

## 作业边界

处理作业题时，agent 应遵循：

1. 先问用户已有思路。
2. 如果没有思路，先问前置概念。
3. 给第一层提示。
4. 让用户继续尝试。
5. 必要时给第二层提示。
6. 最后再给完整解法。
7. 解完后必须做错因或方法归纳。
