# Daily Start

每天开始时按这个流程走。

## 0. 选择模式

先回答一句话：

```text
今天我是来处理：课程 / 作业 / 复习 / 项目 / 论文 / 复盘 / raw data
```

## 1. 读取状态

- `01_LearningDesk/02_今日状态.md`
- `01_LearningDesk/03_行动队列.md`
- `Review/progress.md`
- 当前主线课程 MOC（如已指定课程）

## 2. 选择唯一主任务

今天只选一个：

- CourseOS learning session
- Problem loop
- Course review
- Reading Mission
- Project ability mapping
- Weekly review

## 3. 压缩范围

合格范围：

- 一个小节
- 10-20 页课件
- 2-5 道题
- 一个复习对象
- 一篇论文的 L0/L1
- 一个项目最小任务

不要把“学一章”“复习整门课”“整理所有资料”作为今日任务。

## 4. 复习债务路由

- Daily Start 只提示有无到期复习，不插入复习任务。
- 只有用户选择复习模式时，才读取并展开 `Review/revision_notes.md`。
- 作业或课程模式下，只有直接阻塞当前题/主题时，才插入 3-10 分钟前置工具补丁。

## 5. 先让学习者输出

Agent 先问：

- 你已经懂什么？
- 你第一步会怎么做？
- 你卡在哪里？

复习模式则先让学习者冷复测输出，不先重讲。

## 6. 结束记录

日常收口写进当天 Daily Note 的 5 行。

只有结构性事件才更新：

- 总进度
- 课程进度
- 错题或概念卡
- 复习债务
- 行动队列状态
