# Daily Start

每天开始时按这个流程走。

## 1. 读取状态

- `Review/progress.md`
- 当前主线课程 MOC
- 当前 raw 接入队列

## 2. 选择唯一主任务

今天只选一个：

- CourseOS learning session
- Problem loop
- Reading Mission
- Project ability mapping
- Weekly review

## 3. 压缩范围

合格范围：

- 一个小节
- 10-20 页课件
- 2-5 道题
- 一篇论文的 L0/L1
- 一个项目最小任务

## 4. 先让学习者输出

Agent 先问：

- 你已经懂什么？
- 你第一步会怎么做？
- 你卡在哪里？

## 5. 结束记录

更新：

- 总进度
- 课程进度
- 错题或概念卡
- 下一步最小动作
