# ResearchWiki Index

ResearchWiki 用于研究方向、论文、概念、连接和开放问题。

## 入口

- `papers/paper_index.md`
- `concepts/concept_index.md`
- `connections/connection_index.md`

## 规则

- 先写 Reading Mission，再读论文。
- 大多数论文只读 L0/L1。
- 不为每个陌生名词建页。
- 只有对课程、项目或研究问题有价值的内容才沉淀。
