# Raw

非课程资料的原始资料暂存区。

课程资料放 `10_Courses/`，不放在这里。

## 放什么

- `papers/`：论文
- `books/`：书籍
- `clips/`：网页剪藏
- `projects/`：项目素材
- `assets/`：通用附件（图片、模板等）

## 规则

- 课程资料不放这里，放 `10_Courses/`。
- 不改写 raw 文件。
- 不把 raw 当成学习成果。
- 大文件优先放在 Vault 外部，只在 `60_Resources/ExternalIndexes/external_material_index.md` 中记录路径。
