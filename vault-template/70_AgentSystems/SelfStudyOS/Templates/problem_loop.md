# Problem Loop

适用：作业题、例题、错题重做。

## 基本信息

```text
日期：
课程：
题目来源：
题号：
相关知识点：
```

## 第 0 步：用户先尝试

在 agent 给解法前，学习者先写：

```text
我对题目的理解：
我认为要用的知识点：
我的第一步：
我卡住的位置：
```

如果完全不会，也要写：

```text
我完全不会，因为：
```

## 第 1 步：Agent 分层提示

提示等级：

- Hint 1：指出方向，不给公式展开。
- Hint 2：指出关键公式或定理。
- Hint 3：展示下一步变形。
- Solution：完整解法。

默认先给 Hint 1。

## 第 2 步：用户继续尝试

```text
根据提示后的尝试：
新的卡点：
```

## 第 3 步：解后归因

错因可选：

- 概念不清
- 公式不会用
- 计算失误
- 题型没见过
- 读题建模失败
- 前置知识缺失
- 用 AI 敷衍

## 第 4 步：沉淀

```text
这题的核心套路：
下次遇到类似题先看什么：
是否进入错题卡：
是否生成概念卡：
```
