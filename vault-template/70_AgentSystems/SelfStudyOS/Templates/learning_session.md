# Learning Session

适用：一节课、一个主题、一个知识点。

## 基本信息

```text
日期：
课程/领域：
材料路径：
本次范围：
deadline：
```

## 启动问题

1. 我今天要学什么？
2. 这个内容在课程、项目或科研里的位置是什么？
3. 我已经知道什么？
4. 我最可能卡在哪里？
5. 今天结束时，什么算完成？

## Agent 处理

### Global orientation

说明这个内容在整体中的位置。

### Core extraction

提取：

- 核心概念
- 公式/定理
- 前置知识
- 最小例子
- 常见误区

### Check understanding

Agent 需要问学习者 2-5 个问题，而不是直接继续讲。

## 学习证据

```text
我能复述：
我能做的题：
我只是看懂但不会做：
我还不懂：
```

## 结束记录

```text
今天完成：
最大卡点：
下一步：
是否需要生成错题/概念卡：
```
