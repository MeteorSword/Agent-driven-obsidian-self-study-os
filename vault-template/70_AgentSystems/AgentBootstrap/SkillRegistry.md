# Skill Registry

记录推荐使用的 agent skills 或工具。

## 推荐技能类型

| Skill | 用途 |
|---|---|
| selfstudyos-workflow | SelfStudyOS 启动、日常学习调度、ResearchWiki/ProjectLab（v1.0 占位）；资料归档见 agent-material-intake，课程执行见 selfstudyos-course-workflow |
| selfstudyos-course-workflow | 课程执行入口，覆盖四个子模式：开始学习、作业、复习、考试冲刺 |
| agent-material-intake | 文件归档唯一入口，课程资料路由到 10_Courses，非课程资料路由到 Raw |
| agent-memory-write | 写记忆唯一入口，feedback 查重、格式模板、MEMORY 索引同步 |
| agent-exam-mapping | 真题按知识点索引唯一入口，读真题内容标注知识点考法难度，更新 exam_topic_index |
| agent-weekly-review | 周复盘唯一入口，读 Daily Note 和 progress 对照 6 个问题诚实复盘，连续两周虚假进展预警 |
| pdf | 读取、抽取、检查 PDF；适合教材、论文、课件 |
| math-reasoning | 推导、证明、公式解释、数学符号整理 |
| exam-prep | 期末复习计划、复习材料、弱点诊断 |
| quiz / quiz-maker | 理解测验和练习题 |
| doc-coauthoring | 报告、论文综述、项目文档共写 |

## 使用策略

- 优先使用本地已安装、来源可信的技能。
- 外部技能先看来源、维护状态和实际需求。
- 不因为工具新就引入。
