# Courses

课程资料和课程输出区。

建议结构：

```text
10_Courses/
  2026Spring/
    CourseName/
      raw/
      notes/
      assignments/
      problems/
      mistakes/
      review/
      outputs/
      CourseName-MOC.md
  CourseArchive/
```

SelfStudyOS 第一阶段也可以先把课程执行层放在：

```text
70_AgentSystems/SelfStudyOS/CourseOS/
```

等某门课跑通后，再决定是否同步到 `10_Courses/`。
