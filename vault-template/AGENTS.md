# AGENTS.md — Vault 根

这份文件只做一件事：告诉 agent **新会话从哪开始**。它不存任何学习内容，也不需要你经常改。

## 新会话先读

1. `01_LearningDesk/06_给Agent的启动句.md` — 冷启动协议与四个模式在这里
2. `70_AgentSystems/SelfStudyOS/AGENTS.md` — agent 系统子目录的工作约定
3. `01_LearningDesk/02_今日状态.md` 与 `03_行动队列.md` — 今天做什么

## 用户只说三个字时

用户说「冷启动」「开工」「今天学什么」时，直接执行 `06_给Agent的启动句.md` 第 1 段的冷启动协议：

读入口文件 → 报告六件事（当前主线 / 今天 P0 / 有无到期复习 / 建议唯一任务 / 本次模式 / 用户要先输出什么）→ **停下等确认**。

不要反问"你今天想做什么"，也不要跳过读取直接给建议。

## 不要做的事

- **不要把当期学习计划写进 `06_给Agent的启动句.md`**。它是协议文件，只写"怎么做"。当期计划写 `Review/study_plan.md`，当期主线写 `02_今日状态.md`。
- 不要把真实课程名、考试日期、本机路径写进本文件。
- 不要在用户没有确认的情况下批量修改或删除文件。
- 不要用"看懂了 / 整理完了"当作学习完成。

## 平台兼容

- Codex / DSH 等读 `AGENTS.md` 的工具：本文件即入口。
- Claude Code 读 `CLAUDE.md`：该文件只有一行指向本文件。
- 不读任何说明文件的工具：让用户手动贴 `06` 第 2 段的粘贴块。
