# SelfStudyOS Vault Template

把这个目录复制到你的 Obsidian Vault，或把里面的目录合并进已有 Vault。

## 推荐入口

```text
70_AgentSystems/AgentBootstrap/START_HERE_FOR_AGENT.md
70_AgentSystems/SelfStudyOS/home.md
```

## 顶层目录

- `00_Inbox/`：临时捕捉。
- `10_Courses/`：课程资料和课程输出。
- `20_Projects/`：项目、作品集、实践记录。
- `30_Research/`：论文、方向、研究问题。
- `40_Knowledge/`：跨领域稳定知识。
- `50_LifeOps/`：可选生活与任务系统。
- `60_Resources/`：外部资料索引。
- `70_AgentSystems/`：SelfStudyOS、agent 规则、模板。
- `80_Attachments/`：附件，本模板不追踪实际文件。
- `90_Archive/`：归档。
- `99_Meta/`：Vault 规则和迁移记录。

## 第一次使用

1. 改写 `70_AgentSystems/SelfStudyOS/System/learner_profile.md`。
2. 改写 `70_AgentSystems/SelfStudyOS/Review/progress.md`。
3. 把 `CourseOS/ExampleCourse` 复制或重命名为你的主线课程。
4. 用 `prompts/01_general_start.md` 启动 agent。
