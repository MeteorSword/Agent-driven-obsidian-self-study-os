# 周复盘

这个 skill 是周复盘的唯一入口。所有每周学习系统复盘操作都通过这里完成。

## 为什么要这个 skill

学习系统最大的风险不是资料不够，而是虚假进展：整理了结构但没做题、看懂了解析但没独立推导、做了题但错因没归因。周复盘用固定问题逼自己诚实面对一周真实学习证据，区分有效进展和虚假进展。

## 复盘流程

### 1. 读取本周学习证据

读本周的 Daily Note（`${DAILY_NOTE_DIR}` 下本周日期范围的文件），提取每条 5 行收口记录。

读 `${REVIEW_PROGRESS}` 的学习证据段，看本周新增了哪些证据。

### 2. 对照周复盘问题逐一回答

读取 `${WEEKLY_REVIEW}` 的 6 个问题，逐一诚实回答。不自行定义问题，问题定义见 `${WEEKLY_REVIEW}`。

不美化，不编造。没有证据就写"无"。

### 3. 输出复盘报告

按 `${WEEKLY_REVIEW}` 的输出格式写：

```text
本周有效进展：
本周虚假进展：
最大能力缺口：
下周唯一主任务：
明天第一步：
```

### 4. 记录到 Daily Note 和 progress

在当天 Daily Note 追加复盘报告。

如果复盘发现下周主线变化，更新 `${TODAY_STATUS}` 的主线和 `${REVIEW_PROGRESS}` 的当前阶段。

### 5. 连续虚假进展预警

如果连续两周复盘报告"虚假进展"非空，在 `${REVIEW_PROGRESS}` 当前阶段段显式标注"连续两周虚假进展，需调整学习策略"。

## 硬约束

- **诚实回答，不美化进展。**
- **基于真实证据**（Daily Note 5 行收口、`${REVIEW_PROGRESS}` 学习证据），不凭印象。
- **没有证据就写"无"，不编造。**
- **连续两周虚假进展必须报告，不隐瞒。**

## 边界

这个 skill 只管周复盘。不管：
- 日常学习调度（那是 selfstudyos-workflow 的事）
- 做题和课程执行（那是 selfstudyos-course-workflow 的事）
- 归档资料（那是 agent-material-intake 的事）
- 写记忆（那是 agent-memory-write 的事）
