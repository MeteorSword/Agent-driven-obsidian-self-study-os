# 真题映射

这个 skill 是真题按知识点索引的唯一入口。所有真题→知识点的映射操作都通过这里完成。

## 为什么要这个 skill

用户归档真题后，真题只是作为文件存在 `10_Courses/<课程名>/真题/` 下。没有"真题→知识点"的正向映射，agent 在学某个知识点时不知道这个知识点在真题里考过没有、怎么考、难度如何。

这个 skill 建立真题按知识点的索引，让开始学习模式能扫描真实考法，学习内容围绕真题反推。

## 映射流程

### 1. 确认课程和真题文件位置

确认课程名和真题文件路径。真题文件在 `10_Courses/<课程名>/真题/` 下。

### 2. 读取真题内容

读取真题文件（PDF/截图/PPT）。逐题识别每道题的内容。

### 3. 逐题标注

对每道题标注四个字段：

- **知识点**：对应 `${CONCEPT_INDEX}` 里已有的概念。如果 `${CONCEPT_INDEX}` 没有对应概念，先在 `${CONCEPT_INDEX}` 新建占位概念卡，再标注。
- **考法**：这道题考了这个知识点的什么（计算/证明/应用/推导/判断）
- **难度**：易/中/难
- **题号**：真题里的题号（如 Exam-2024-Q3）

不确定知识点时问用户，不猜。

### 4. 更新索引

在 `${EXAM_TOPIC_INDEX}` 建立或更新索引表。新增一行或追加到已有行。

### 5. 记录到 Daily Note

在当天 Daily Note 里加一行：

```markdown
- 真题映射：<课程名> <年份> 真题 → <知识点数量> 个知识点已索引
```

## 硬约束

- **只做映射，不改真题原文件。**
- **知识点必须对应 `${CONCEPT_INDEX}` 已有概念，或新建占位概念卡后标注。**
- **不确定知识点时候问用户，不猜。**
- **每次只处理一套真题，不批量处理。**
- **考法和难度基于题目内容判断，不确定时问用户。**

## 边界

这个 skill 只管真题映射。不管：
- 归档（那是 agent-material-intake 的事）
- 做题（那是 selfstudyos-course-workflow 的事）
- 写记忆（那是 agent-memory-write 的事）

## 协作关系

agent-material-intake 归档真题后会提示"是否建立知识点索引"。用户同意后调用本 skill。两个 skill 通过用户确认衔接，不自动串联。
