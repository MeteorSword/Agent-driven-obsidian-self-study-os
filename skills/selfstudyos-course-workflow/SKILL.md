# 课程学习工作流

这个 skill 是课程执行的入口。包含四个子模式，共用 Hint 分层和收口规则。

`${OPERATING_RULES}` 已定义三模式和 Hint 分层的规则。这个 skill 不重复规则，只定义执行步骤。

## 选择子模式

用户说以下哪种就进对应模式：

| 用户说什么 | 进入 | 对应旧 prompt |
|-----------|------|--------------|
| "学新内容""学概念""学一节课" | 开始学习模式 | 02_course_session |
| "做题""作业""刷题" | 作业模式 | 03_problem_loop |
| "复习""冷复测""错题订正""概念查漏" | 复习模式 | 09_course_review |
| "考试冲刺""期末冲刺""考前复习" | 考试冲刺 | 08_exam_sprint |

## 通用前置

所有子模式开始前：

1. 确认课程名（用户指定或从 `${TODAY_STATUS}` 获取）。
2. 读对应 `${COURSE_MOC}` 和 progress。
3. 检查是否有 `status: in-progress` 的 session/problem。
4. 如果当前状态、课程 progress、MOC 的下一步冲突，先报告冲突，再选最小学习单元。
5. 如果 `${ACTION_QUEUE}` 中有到期复习，只简短提示"有到期复习，可切换复习模式处理"；不展开，不安排热身。

## 开始学习模式

适用：学新概念、新公式、新章节，还没准备直接做作业。

流程：

1. 读对应 `${COURSE_MOC}` 和 `${MATERIAL_QUEUE}`。
2. 先扫描课后习题和 `${EXAM_TOPIC_INDEX}`，了解本节真实考法、题型和难度。扫描范围包括：教材章末习题、历年考试真题（通过 `${EXAM_TOPIC_INDEX}` 索引）、老师作业题。学习内容围绕课后题型反推，不随便造与作业脱节的基础题。
3. 把范围压到一个最小学习单元（一节/一个概念/一个公式）。
4. 问 2-5 个诊断问题，判断用户当前懂到哪。
5. 根据回答教学，不长篇总结。
6. 如果某个历史复习债务直接阻塞本次主题，只做 3-10 分钟前置工具补丁，标明不计入掌握证据，回到本次主题。
7. 学完后要求复述、举例或做一个最小题。
8. 结束时记录：掌握了什么、卡什么、下一步做什么。

硬规则：
- 不把资料直接总结成长文。
- 不默认用户已经会旧笔记里的内容。
- 不主动读取或展开 `${REVISION_NOTES}`。
- 如果用户想跳过基础，直接指出风险。
- 桥接题允许使用，但不计入掌握证据，必须显式标记。

## 作业模式

适用：做作业题、教材习题、真题。

流程：

1. 确认题源：用户指定的作业、教材题、截图、PDF、或从 `${MATERIAL_QUEUE}` 取。
2. 不替用户造题。
3. 先要求用户给出尝试、思路、草稿或明确卡点。
4. 如果用户没有思路或无法表达卡点，先问前置概念：确认用户是否缺少本次题目所需的前置概念。如果确认概念缺失，先做 3-10 分钟前置工具补丁（规则见 `${OPERATING_RULES}` 桥接题与前置工具补丁段），然后回到原题。
5. 判断卡点类型：概念、公式、计算、建模、题型识别、粗心。
6. 按 Hint 1 → Hint 2 → Hint 3 分层提示。
7. 每次只给当前 Hint 等级；给出后必须停止，等待用户继续。
8. 只有用户尝试后仍卡住，才给下一层或完整解法。
9. 做完后必须归因：这题暴露了什么能力缺口。
10. 如果值得复习，生成错题卡草稿并建议保存位置。
11. 不主动读取或展开 `${REVISION_NOTES}`。
12. 如果某个复习债务直接阻塞当前题，只做 3-10 分钟前置工具补丁，标明不计入作业完成度/掌握证据，回到原题。

卡点归因必须区分：
- 主卡点：真正让用户停下来的地方。
- 末端错误：已经会做后，在计算、整理、抄写中出现的小错。
- 错题卡和复习任务优先依据主卡点。

题号规则：会话内自动用 Q1/Q2/Q3 编号，收口时转换为来源格式（见 `${OPERATING_RULES}` 题号格式段）。

掌握等级（不跳级）：
```
预热通过 → 桥接通过 → 作业题通过 → 变式通过
```

## 复习模式

适用：错题回看、冷复测、间隔复习、概念查漏。

注意：考前 1-3 周的大范围计划用考试冲刺模式，不混用。

流程：

1. 读对应 `${COURSE_MOC}`、progress、错题索引。
2. 读 `${REVIEW_ENTRY}` 和 `${REVISION_NOTES}`。本模式是默认读取并展开复习债务的模式。
3. 判断复习类型：冷复测 / 错题订正 / 概念查漏 / 间隔复习。
4. 冷复测：先让用户不看提示独立写，不先讲解。
5. 错题订正：先让用户复述原错因和这次准备检查的步骤。
6. 概念查漏：先问 2-3 个诊断问题，再给最小解释。
7. 复习完成后，记录通过方式：无提示 / Hint 1 / Hint 2 / Hint 3 / Solution 后订正。
8. 只有连续暴露同类问题时，才建议更新 `${REVISION_NOTES}`、错题卡或 `${ACTION_QUEUE}`。

硬规则：
- 复习债务只在本模式默认展开。
- 复习不是重看讲解；优先冷复测和输出。
- 不把"看懂了"记成"通过"。
- 不直接把答案写给用户；先要用户写尝试或复述。
- 每次只复习一个小范围。

## 考试冲刺模式

适用：考前 1-3 周，压缩范围、查漏补缺、建立题型和错题优先级。

流程：

1. 让用户列出最不稳的 3 个主题。
2. 按分值、可提升空间、前置依赖排序。
3. 只选今天能完成的最小复习任务。
4. 用题型和错题驱动复习，不重读全部资料。
5. 每轮结束记录：会了什么、错因是什么、下一题练什么。

注意：
- 读 `${STUDY_PLAN}`（如果存在），对照考试日历确认今天该做什么。
- 如果 study_plan 有当天的计划，优先按 study_plan 执行，不另起炉灶。
- 冲刺模式可以和复习模式叠加（在冲刺框架下做冷复测）。

输出：
- 复习优先级
- 今天最小任务
- 练习题型
- 错题归因
- 下一轮动作

## 收口

所有子模式结束时，按 `${LEARNING_CLOSE_5LINES}` 写 5 行进当天 Daily Note。

5 行不替代结构性更新。只有以下事件才另开文件：
- 出现新错题 → 加错题卡 + 课程 progress 错因表加一行
- 出现新复习债务 → `${REVISION_NOTES}` 加一段
- 完成新题号 → 课程 progress 已完成题目加一行
- 主线推进到新章 → 改 `${TODAY_STATUS}` 当前主线
- 任务完成或 archive → `${ACTION_QUEUE}` 更新 status
